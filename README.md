# Data Analysis with Python

This project is part of my **Data Science Internship at Codomax Digital Solutions**.

In this task, I worked with a customer dataset using **Python, Pandas, and NumPy** and practiced the basic steps involved in data analysis.

## 📌 Task Overview

The main objective of this task was to understand a dataset, clean the data, and perform basic analysis to find useful information.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## 📊 Work Done

* Imported the CSV dataset
* Explored the dataset using Pandas
* Checked rows, columns, and data types
* Identified missing values
* Cleaned and organized the data
* Performed basic data analysis
* Created basic visualizations
* Observed useful patterns and insights from the dataset

## 📁 Files

* `sample-customers.csv` – Dataset used for analysis
* `Data_Analysis_with_Python.ipynb` – Google Colab notebook containing the complete analysis

## 🎯 Learning Outcome

Through this task, I gained practical experience in working with CSV datasets and learned how **Pandas and NumPy** can be used to explore, clean, and analyze data using Python.
